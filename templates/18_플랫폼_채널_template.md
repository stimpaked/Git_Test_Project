## 완료 체크 (18)

- [ ] 플랫폼·채널 목록의 모든 칸이 값, `해당 없음`, `미정` 중 하나로 닫혔다
- [ ] 입력의 플랫폼 후보가 모두 목록에 있고 후속과 제외도 범위 구분으로 표시되었다
- [ ] 범위 구분이 `포함`인 플랫폼마다 점검 주제 열여덟 가지가 모두 한 행 이상 있다
- [ ] `공통 대응`, `성립하지 않음`, `범위 밖` 행은 차이·제약이 `해당 없음`과 사유로 닫혔고 `전용 대응` 행은 차이·제약에 값이 있다
- [ ] 플랫폼 정책에서 나온 판정은 근거에 정책 문서의 이름과 확인일이 있거나 출처 유형이 `일반 지식(미검증)`으로 표시되었다
- [ ] `전용 대응` 행마다 기능 후보의 출처에 있거나 근거가 입력 산출물의 기존 후보를 가리킨다
- [ ] 기능 후보의 출처 `LD-` ID와 적용 플랫폼 `LP-` ID가 모두 앞 표에 있다
- [ ] 설계 기준과 후속 후보가 기능 후보와 구분되어 있다
- [ ] 릴리스 영향의 플랫폼 ID가 모두 플랫폼·채널 목록에 있다
