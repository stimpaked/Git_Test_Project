## 완료 체크 (33)

- [ ] 모든 표의 모든 칸이 값, `해당 없음`, `미정` 중 하나로 닫혔다
- [ ] 호출 표의 호출 기능과 호출받는 기능이 기능 트리에 있는 ID이거나 호출받는 기능이 `미정`이다
- [ ] 호출받는 기능이 모두 공통·고유가 공통인 기능이고 공통 기능 칸이 공통 기능 목록의 `DC-`이거나 `미정`이다
- [ ] 같은 호출 기능과 호출받는 기능의 쌍이 호출 표에 두 번 나오지 않는다
- [ ] 선후행 표의 후행 기능이 공통이면 선행 기능도 공통이다
- [ ] 호출 표에 쓴 기능 쌍이 선후행 표에 다시 쓰이지 않았다
- [ ] 호출과 선후행을 함께 따라가도 순환이 없고 자기 자신을 호출하거나 선행으로 삼는 행이 없다
- [ ] 기능 트리의 모든 기능이 웨이브 표에 정확히 한 행 있다
- [ ] 웨이브가 숫자인 행은 선행이 없으면 0이고 선행이 있으면 기준 선행의 웨이브보다 1 크며 기준 선행이 선행 가운데 웨이브가 가장 늦은 기능이다
- [ ] 기능 트리의 공통 기능이 모두 공통 기능 검사 표에 정확히 한 행 있고 호출 행이 있는 기능만 판정이 호출됨이다
- [ ] 판정이 직접 근거로 유지인 행의 직접 근거가 근거 ID이고 판정이 과잉 의심인 행은 직접 근거를 `해당 없음`(사유)으로 닫았다
- [ ] 호출받는 기능이 `미정`이거나 기능 트리에 없는 호출이 집계의 호출 대상 미정 수와 정의되지 않은 참조 수에 세어졌다
- [ ] 후속이 아닌 기능이 후속 기능에 기대는 행이 집계의 후속 의존 수에 세어졌다
- [ ] 집계의 검사 합계가 입력 공통 기능 수와 같고 웨이브 행 수가 입력 기능 수와 같다
- [ ] 입력에 없는 기능 ID, 호출, 선후행이 값으로 쓰이지 않았다
