## 완료 체크 (03)

- [ ] 조사 개요의 다섯 항목이 값, `해당 없음`, `미정` 중 하나로 닫혔다
- [ ] 근거 칸의 `조사:`마다 출처(링크나 문서 이름), 확인일, 버전이 있다
- [ ] 직접 확인하지 못한 값은 `일반 지식(미검증):`, `가정:`, `미정` 중 하나로 닫혀 있고 `조사:`로 쓴 것이 없다
- [ ] 사용자 조사의 모든 행에 조사 대상과 종류가 있고 사용자의 말이 조사 기록의 인용이거나 닫는 말로 닫혔다
- [ ] 사용자 조사의 모든 행에서 관련 가설이나 영향 영역 중 하나 이상이 값이다
- [ ] 비교 기능의 모든 기능이 기능별 제공 현황에 유사 서비스마다 한 행씩 있고 같은 조합이 두 번 나오지 않는다
- [ ] 기능별 제공 현황의 기능과 서비스가 모두 비교 기능과 유사 서비스에 있다
- [ ] 규제·정책의 모든 행에 종류, 요구 유형, 적용 여부, 근거가 있다
- [ ] 기술 제약의 모든 행에 종류, 관련 대상, 선정 상태, 영향이 있다
- [ ] 입력에 없는 법령 이름, 업체 이름, 한도, 기간, 조사 대상 수가 값으로 쓰이지 않았다
