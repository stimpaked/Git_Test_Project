- [ ] 요구 목록의 모든 칸이 값, `해당 없음`, `미정` 중 하나로 닫혔고 입력에 없는 목표값·업체·수치가 값으로 쓰이지 않았다
- [ ] 요구 목록의 모든 행에 지표가 있고 목표값과 측정 방법이 값이거나 `미정`(확인처·담당·기한)으로 닫혔다
- [ ] 요구 목록의 특성이 선택지 값이고 처리가 승격, 기준, 설계 중 하나다
- [ ] 특성 점검 열세 항목이 모두 값, `해당 없음`, `미정` 중 하나로 닫혔다
- [ ] 값으로 닫은 특성 점검 항목의 답에 쓴 요구 ID가 모두 요구 목록에 있고 그 행의 특성과 점검 항목이 맞는다
- [ ] 요구 목록의 모든 행이 특성 점검의 답에 한 번 이상 나온다
- [ ] 처리가 승격인 행은 기능 후보의 출처에 있거나 근거가 입력 산출물의 기존 후보를 가리킨다
- [ ] 처리가 설계인 행은 기능 후보의 출처에 있고 그 후보의 구분이 설계 기준이거나, 근거가 입력 산출물의 같은 설계 기준 후보를 가리킨다
- [ ] 기능 후보의 출처 `QN-` ID가 모두 요구 목록에 있다
- [ ] 후속 후보, 설계 기준, 프로세스가 기능 후보와 구분되어 있다
