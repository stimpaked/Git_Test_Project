## 완료 체크 (20)

- [ ] 입력 산출물의 모든 후보가 후보 판정 표에 한 행씩 있다
- [ ] 모든 행에 판정과 근거가 있고, 잠정 구분과 판정이 다른 행은 근거에 바꾼 이유가 있다
- [ ] 판정이 공통이거나 혼합인 행마다 공통 기능 ID가 있고 그 ID가 공통 기능 표에 있다
- [ ] 공통 기능마다 후보 판정 표에 그 ID를 가리키는 후보가 한 개 이상 있다
- [ ] 판정이 혼합인 후보마다 혼합 분리 표에 한 행 이상 있다
- [ ] 신규 후보의 출처와 혼합 분리의 고유 정책 후보가 후보 판정 표나 신규 후보 표에 있다
- [ ] 같은 종류의 장치를 따로 필요로 하는 후보가 고유로 따로 남아 있지 않다
- [ ] 대표 호출 후보의 ID가 모두 판정이 고유인 후보다
- [ ] 집계의 합계가 입력 후보 수와 같다
