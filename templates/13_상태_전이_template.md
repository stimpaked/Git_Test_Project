## 4. 상태도

> 작성 지침: 3번 표를 닫은 뒤에 그린다. 1번 표에서 `상태 있음`인 엔티티마다 `###` 소절을 하나씩 쓴다. 상태는 2번 표의 이름 그대로 노드로, 전이는 선으로 그리고 선의 레이블은 `전이 ID 계기 이름`이다. `[*]`에서 나가는 선은 `(생성 전)`, `[*]`로 들어오는 선은 `(소멸)`을 뜻한다. 상태 이름에 공백이나 괄호를 쓰면 렌더링이 깨질 수 있다. 3번 표의 모든 전이가 한 번씩 그려져야 한다.

## 완료 체크 (13)

- [ ] 엔티티 목록의 모든 엔티티가 대상 엔티티 표에 한 줄씩 있고 상태 유무가 정해졌다
- [ ] 상태 있음인 엔티티마다 상태 목록에 상태가 한 개 이상 있고 상태 이름이 엔티티 안에서 겹치지 않는다
- [ ] 모든 전이의 시작 상태와 종료 상태가 같은 엔티티의 상태 ID이거나 `(생성 전)`, `(소멸)`이다
- [ ] 모든 전이에 계기, 계기 유형, 계기 주체가 있고 모르는 칸은 `미정`으로 닫았다
- [ ] 모든 전이가 기존 후보 칸에 앞 단계 후보를 쓰거나 후보 목록의 출처에 쓰였다
- [ ] 시간 유형 전이의 계기 주체가 비사람 액터 목록의 시간 트리거 액터이고 운영 유형 전이의 계기 주체가 운영·지원 사람 액터이다
- [ ] 끝 상태가 아닌 모든 상태에서 나가는 전이가 있고 `(생성 전)`에서 시작하는 길로 모든 상태에 닿는다
- [ ] 상태 있음인 엔티티마다 상태도가 있고 상태도의 상태와 선이 상태 목록과 전이표와 같다
- [ ] 상태 점검에 상태 있음인 엔티티마다 한 줄이 있고 `있음`으로 쓴 점검마다 후보 목록에 출처가 있다
- [ ] 후보 목록의 후보마다 출처가 있고 기능이 아닌 항목이 섞이지 않았다
