## 완료 체크 (11)

- [ ] 유저 플로우의 등장 명사 표에 있는 모든 명사가 명사 매핑에 한 줄 이상 있다
- [ ] 명사 매핑의 엔티티 칸이 가리키는 ID가 모두 엔티티 목록에 있다
- [ ] 엔티티로 채택한 명사의 이름이 엔티티 목록의 해당 엔티티 이름과 같다
- [ ] 속성으로 흡수한 명사가 가리킨 엔티티의 핵심 속성에 있다
- [ ] 엔티티 아님으로 처리한 명사마다 어느 단계가 다루는지 사유가 있다
- [ ] 엔티티마다 설명, 핵심 속성, 주 소유 액터, 개인정보, 근거가 있다
- [ ] 엔티티 이름이 서로 겹치지 않고 한 줄에 대상이 하나다
- [ ] 개인정보 속성의 이름이 모두 같은 줄의 핵심 속성에 있다
- [ ] 엔티티 목록의 모든 엔티티가 엔티티 관계에 출발이나 대상으로 한 번 이상 나온다
- [ ] 같은 대상의 다른 이름으로 처리한 모든 명사가 용어집의 사용하지 않는 동의어에 있다
- [ ] 용어집의 한 줄에 용어가 하나이고 엔티티 이름과 표준 용어가 서로 다른 말로 쓰이지 않는다
- [ ] 화면 이름, 기능 이름, 서비스 안의 구성요소가 엔티티에 없다
