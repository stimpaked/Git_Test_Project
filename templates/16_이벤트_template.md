## 완료 체크 (16)

- [ ] 모든 이벤트에 발생 기능이 있고 알림·로그·분석·후속 처리 중 하나 이상에 소비 기능이 있다
- [ ] 이벤트의 모든 칸이 값, `해당 없음`, `미정` 중 하나로 닫혔다
- [ ] 이벤트 한 행이 사건 하나를 담고 같은 사건이 두 행에 없다
- [ ] 이벤트마다 근거가 입력 산출물의 문서와 위치를 가리킨다
- [ ] 소비 기능과 발생 기능마다 입력 산출물의 기존 후보 ID가 있거나 기능 후보 표에 행이 있다
- [ ] 기능 후보의 출처 `VE-` ID가 모두 이벤트 목록에 있다
- [ ] 후속 후보와 설계 기준이 기능 후보와 구분되어 있다
