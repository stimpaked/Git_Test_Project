- [ ] 답이 값인 점검 항목마다 출처로 올린 타이머가 한 개 이상 있다
- [ ] 사람이 직접 조작해 일어나는 동작과 상대 시스템의 요청으로 일어나는 동작이 타이머에 없다

- [ ] 입력으로 받은 시간 기반 항목(시간 트리거 액터, 그 액터의 목표, 시간이 계기인 전이와 질문)이 모두 입력 대응에 한 줄씩 있다
- [ ] 입력 대응의 타이머 칸이 타이머 ID이거나 `해당 없음`(사유)이다
- [ ] 관련 후보가 `해당 없음`인 타이머는 모두 기능 후보의 출처에 나온다
