## 완료 체크 (26)

- [ ] 운영 점검 관점 열두 항목이 모두 값, `해당 없음`, `미정` 중 하나로 닫혔다
- [ ] 값으로 닫은 점검 관점 항목이 운영 업무의 출처에 한 번 이상 나온다
- [ ] 사람 액터 목록에서 유형이 운영·지원인 액터가 모두 운영 업무의 액터에 한 번 이상 나온다
- [ ] 운영 업무의 모든 칸이 값, `해당 없음`, `미정` 중 하나로 닫혔다
- [ ] 기존 화면, 필요한 권한이 입력 산출물에 있는 ID이거나 `해당 없음`(사유), `미정`(확인처·담당·기한)이다
- [ ] 도구 판정이 새 도구 필요인 업무마다 도구 후보의 출처에 나온다(입력 산출물에 같은 기능의 후보가 있으면 근거가 그 ID를 가리키는 추적용 행이다)

- [ ] 도구 형태가 새 화면인 후보와 기존 화면에 추가인 후보의 화면이 화면 인벤토리와 대조되었다
- [ ] 후속 후보, 설계 기준, 프로세스가 기능 후보와 구분되어 있다
