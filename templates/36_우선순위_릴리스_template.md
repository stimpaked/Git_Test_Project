## 완료 체크 (36)

- [ ] 모든 표의 모든 칸이 값, `해당 없음`, `미정` 중 하나로 닫혔다
- [ ] 기능 트리의 모든 기능이 우선순위 표에 정확히 한 행 있고 기능 ID가 기능 트리에 있는 ID이다(기능을 지우거나 합치지 않았다)
- [ ] 기능 게이트마다 우선순위 표의 게이트 칸에 한 번 이상 나오고, 프로세스 게이트는 게이트 칸에 나오지 않는다
- [ ] 게이트 칸이 값인 기능은 우선순위가 필수이고 릴리스가 MVP이다
- [ ] 필수 기능이 호출받는 기능이나 선행 기능으로 삼은 기능은 우선순위가 필수이다
- [ ] 우선순위가 필수인 기능은 릴리스가 MVP이다
- [ ] 호출받는 기능이나 선행 기능의 릴리스가 호출 기능이나 후행 기능의 릴리스보다 뒤가 아니다
- [ ] 기능 트리의 구분이 후속인 기능은 릴리스가 후속이거나, 근거에 앞당긴 이유와 의존성 산출물의 행이 있다
- [ ] 용량 표의 구현 용량이 개발 용량에서 버퍼를 뺀 값이고 공수 단위가 모든 행에서 같다
- [ ] 릴리스별 공수 합이 구현 용량 이내이거나, 넘는 릴리스가 집계의 용량 초과 릴리스 수에 세어지고 사용자에게 알렸다
- [ ] 개발팀이 주지 않은 공수, 용량, 오너, 선언일이 값으로 쓰이지 않았다
- [ ] 기준선의 구성에 계층·ID·태그, 의존성, 우선순위·릴리스 산출물이 모두 있고 버전이 각 산출물 머리말의 버전과 같다
- [ ] 재검토의 관련 목표와 대상이 모두 입력 산출물에 있는 ID이거나 `해당 없음`(사유)이다
- [ ] 집계의 수가 표의 행 수와 맞고 우선순위별 수의 합과 릴리스별 수의 합이 우선순위 행 수와 같으며 게이트 구분별 수의 합이 게이트 수와 같다
- [ ] 입력에 없는 기능 ID, 규제, 게이트, 공수, 용량이 값으로 쓰이지 않았다
