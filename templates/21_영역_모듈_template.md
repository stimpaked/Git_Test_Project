## 완료 체크 (21)

- [ ] 배치 방침과 영역 목록의 모든 칸이 값, `해당 없음`, `미정` 중 하나로 닫혔다
- [ ] 영역 코드와 영역 이름이 영역 사이에서 겹치지 않는다
- [ ] 영역이 화면 하나나 기능 하나, 액터 하나의 이름이 아니라 엔티티와 업무 단위로 나뉘어 있다
- [ ] 엔티티 목록의 모든 엔티티가 엔티티 배정에 정확히 한 줄 있다
- [ ] 목표 목록의 모든 목표가 목표 배정에 정확히 한 줄 있다
- [ ] 공통 기능 목록의 모든 공통 기능이 공통 기능 배정에 정확히 한 줄 있다
- [ ] 엔티티 배정, 목표 배정, 공통 기능 배정의 영역 칸이 영역 목록의 `Z-` ID이거나 `해당 없음`(사유), `미정`이다
- [ ] 영역 칸을 `해당 없음`으로 닫은 목표마다 기능이 아닌 이유와 그 일을 맡는 곳이 사유에 있다
- [ ] 모든 영역이 책임 엔티티, 포함 목표, 배정된 공통 기능 중 하나 이상을 갖는다
- [ ] 운영 기능 배치가 별도 영역을 말하면 그 영역이 영역 목록에 있다
- [ ] 호출 방향 원칙이 영역 목록의 공통·고유 구분과 어긋나지 않는다
