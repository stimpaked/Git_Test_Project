## 완료 체크 (19)

- [ ] 비사람 액터 목록의 외부 시스템·장치·자동 호출 주체 액터마다 연동 정의에 한 줄 이상 있다
- [ ] 연동 정의의 액터 칸이 모두 비사람 액터 목록의 ID이고 시간 트리거 액터와 서비스 안의 구성요소가 없다
- [ ] 연동 정의의 모든 칸이 값, `해당 없음`, `미정` 중 하나로 닫혔고 입력에 없는 업체 이름·한도·비용·기간이 값으로 쓰이지 않았다
- [ ] 연동 정의의 모든 행에 장애 시 동작·재시도·한도·모니터링이 닫혀 있다
- [ ] 공통 점검 열 항목이 모두 값, `해당 없음`, `미정` 중 하나로 닫혔다
- [ ] 연동 정의의 모든 행과 값으로 닫은 공통 점검 항목이 기능 후보의 출처에 한 번 이상 나온다
- [ ] 기능 후보의 출처 ID가 모두 연동 정의나 공통 점검에 있다
- [ ] 후속 후보, 설계 기준, 프로세스가 기능 후보와 구분되어 있다
