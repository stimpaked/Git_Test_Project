## 완료 체크 (32)

- [ ] 모든 표의 모든 칸이 값, `해당 없음`, `미정` 중 하나로 닫혔다
- [ ] 기능 목록의 모든 `FN-`가 기능 트리의 임시 번호나 결번의 임시 번호에 정확히 한 번 나온다
- [ ] 기능 트리의 모든 행이 기능군 하나를 가리키고, 모든 기능군이 영역 목록의 `Z-` 하나를 가리킨다
- [ ] 모든 기능군에 기능이 한 개 이상 있다
- [ ] 기능 ID의 영역 코드가 기능군의 영역의 영역 코드와 같고, 기능 ID가 기능 트리와 결번 전체에서 겹치지 않는다
- [ ] 공통 영역에는 공통 기능만, 고유 영역에는 고유 기능만 있거나, 어긋난 행의 근거에 이유가 있다
- [ ] 기능 목록에서 구분이 후속인 기능이 기능 트리에도 행으로 있고 구분이 후속이다
- [ ] 운영 기능이 예인 행의 액터가 모두 서비스를 운영하는 역할이다
- [ ] 액터, 저니 단계, 플랫폼, 화면, 근거 ID의 ID가 모두 입력 산출물에 있는 ID이거나 `전체`다
- [ ] 근거 등급이 검증인 행의 근거 ID에서 `조사`나 `내부 자료`로 시작하는 근거에 닿고, 미검증인 행의 근거 체인에는 그 둘이 없다
- [ ] 근거 ID가 `미정`인 행의 근거 등급이 `미정`이다
- [ ] 공통 기능 수와 고유 기능 수와 공통·고유 미정 수의 합, 검증 기능 수와 미검증 기능 수와 등급 미정 수의 합이 기능 수와 같다
- [ ] 기능 수에서 후 단계 추가 수를 빼고 결번 가운데 임시 번호가 값인 행의 수를 더하면 입력 기능 수와 같다
- [ ] 입력에 없는 기능, ID, 액터, 화면이 값으로 쓰이지 않았다
