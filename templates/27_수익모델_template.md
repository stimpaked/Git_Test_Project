## 완료 체크 (27)

- [ ] 모든 표의 모든 칸이 값, `해당 없음`, `미정` 중 하나로 닫혔다
- [ ] 지점 종류의 모든 선택지가 지점 점검에 한 행 이상 나온다
- [ ] 판정이 제외나 후속인 행마다 사유와 재검토 조건이 값이거나 `미정`(확인처·담당·기한)이고 `해당 없음`이 아니다
- [ ] 판정이 제외인 행의 근거가 입력 산출물의 항목을 가리키고, 그런 항목이 없으면 판정이 `미정`이다
- [ ] 관련 규제가 규제 매핑의 `RM-` ID이거나 `해당 없음`(사유)이거나 `미정`(확인처·담당·기한)이다
- [ ] 판정이 포함이고 서비스가 외부에 돈을 내는 지점(플랫폼 수수료, 외부 서비스 비용, 획득 비용)마다 비용 구조에 한 행 이상 있고, 비용 구조의 지점이 모두 지점 점검의 ID이다
- [ ] 필요 기능 점검 열두 항목이 모두 값, `해당 없음`, `미정` 중 하나로 닫혔고 답의 `MN-` ID가 모두 지점 점검에 있다
- [ ] 판정이 포함이나 후속인 지점과 값으로 닫은 필요 기능 점검 항목마다 기능 후보가 한 개 이상 있다(입력 산출물에 같은 기능의 후보가 있으면 근거가 그 ID를 가리키는 추적용 행이다)
- [ ] 기능 후보의 출처 ID가 모두 지점 점검, 비용 구조, 필요 기능 점검에 있고 판정이 후속인 지점에서 나온 후보의 구분이 후속 후보이다
- [ ] 후속 후보, 설계 기준, 프로세스가 기능 후보와 구분되어 있다
- [ ] 입력에 없는 가격, 요율, 수수료율, 단가, 법령 이름이 값으로 쓰이지 않았다
