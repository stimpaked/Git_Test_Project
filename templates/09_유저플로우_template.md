## 완료 체크 (09)

- [ ] 목표 목록의 모든 목표가 목표 매핑에 한 줄 이상 있다
- [ ] 플로우 없이 처리하기로 한 목표마다 맡는 단계와 이유가 있다
- [ ] 여러 액터가 같은 방식으로 하는 공통 목표는 한 플로우에서만 그렸다
- [ ] 플로우마다 진입점과 이탈점이 있고 막다른 길이 없다
- [ ] 모든 분기의 전 갈래가 그려져 있다
- [ ] 시작 노드가 아닌 모든 노드에 들어오는 선이, 끝 노드가 아닌 모든 노드에 나가는 선이 있다
- [ ] 미결 질문 목록의 모든 질문이 다이어그램에 그려져 있고 다이어그램의 ❓ 노드가 모두 질문 목록에 있다
- [ ] 다이어그램에 그려진 액터가 플로우 정의의 액터와 같다
- [ ] 등장한 명사·상태·화면이 표에 옮겨졌다
- [ ] 액터 목록에 없는 주체가 다이어그램에 없다
