## 완료 체크 (23)

- [ ] 규제·정책 산출물의 모든 규제 항목이 규제 매핑에 한 행 이상 있거나 `미정`으로 닫힌 사유가 있다
- [ ] 규제 매핑의 모든 행에 대응 유형, 대응 내용, 책임, 출시 게이트, 법무 확인 사항, 근거가 닫혀 있다
- [ ] 대응 불필요 행은 대응 내용, 출시 게이트, 게이트 조건이 `해당 없음`과 사유로 닫혀 있다
- [ ] 대응 내용이 규제 항목의 요건 전체를 덮고, 요건 일부만 덮는 행은 나머지를 다른 행이 덮는다
- [ ] 입력에 없는 법령 이름, 조문, 기한, 기간, 과태료, 기관 이름이 값으로 쓰이지 않았다
- [ ] 규제 점검 열두 항목이 모두 값, `해당 없음`, `미정` 중 하나로 닫혔다
- [ ] 설계 결정의 관련 규제가 모두 규제 매핑의 `RM-` ID이고 법무 확인 전의 방침은 확정 상태가 확인 대기다
- [ ] 기능 후보의 출처 ID가 모두 규제 매핑, 규제 점검, 설계 결정에 있고 규제 항목 ID가 모두 입력 산출물에 있다
- [ ] 대응 유형이 기능인 행과 값으로 닫은 규제 점검 항목마다 기능 후보가 한 개 이상 있다(입력 산출물에 같은 기능의 후보가 있으면 근거가 그 ID를 가리키는 추적용 행이다)
- [ ] 프로세스와 정책 대응은 기능 후보와 구분되어 있고 출시 게이트가 있는 행은 후보의 출처에 나온다
- [ ] 집계의 수가 표의 행 수와 맞고 출시 필수, 조건부 필수, 권고, 대응 불필요 행 수의 합이 매핑 행 수와 같다
