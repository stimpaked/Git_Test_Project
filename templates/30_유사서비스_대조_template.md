## 완료 체크 (30)

- [ ] 모든 표의 모든 칸이 값, `해당 없음`, `미정` 중 하나로 닫혔다
- [ ] 근거 수집의 비교 기능이 모두 대조표와 기능 성격에 한 행씩 있다
- [ ] 근거 수집의 인사이트가 모두 인사이트 대조에 한 행씩 있다
- [ ] 판정이 제외인 행의 범위 항목이 범위·제약의 제외 목록 ID이거나, 입력에 제외 근거가 없으면 판정이 `미정`이다
- [ ] 판정이 개념 없음인 행의 사유가 그 개념이 없음을 보여 주는 닫힌 목록을 가리킨다
- [ ] 판정이 제외나 후속인 행마다 사유와 재검토 조건이 값이거나 `미정`(확인처·담당·기한)이고 `해당 없음`이 아니다
- [ ] 판정이 채택인 행의 후보가 모두 후보 풀에 있는 ID이고 구분이 후속 후보가 아니다
- [ ] 판정이 갭인 행과 후보 풀에 후보가 없는 후속 행마다 갭 목록에 출처가 그 행인 후보가 한 개 이상 있다
- [ ] 갭 목록의 출처가 모두 대조표의 `CP-`나 인사이트 대조의 인사이트 ID이고, 출처가 대조표의 행이면 성격이 기능 성격의 같은 기능과 같다
- [ ] 성격이 값인 행은 분류 근거가 값이고, 성격이 `미정`인 행은 분류 근거도 `미정`이다
- [ ] 성격이 매력인 행의 분류 근거가 사용자 조사나 둘 다이다
- [ ] 집계의 합계가 입력 비교 기능 수와 같고 성격 네 수의 합도 입력 비교 기능 수와 같다
- [ ] 입력에 없는 서비스 이름, 기능 제공 여부, 사용자의 말이 값으로 쓰이지 않았다
