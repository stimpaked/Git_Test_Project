- [ ] 성장 지점의 모든 칸이 값, `해당 없음`, `미정` 중 하나로 닫혔다
- [ ] 입력 산출물의 여정 단계 가운데 발견·가입·인증·온보딩·재방문·유지 구간의 단계마다 성장 지점이 한 행 이상 있거나 제외한 사유가 근거에 있다
- [ ] 성장 지점의 판정이 기존 후보로 충분이면 현재 대응에 후보 ID가 있고, 기능 필요이면 기능 후보의 출처에 나온다
- [ ] 성장 점검 열두 항목이 모두 값, `해당 없음`, `미정` 중 하나로 닫혔다
- [ ] 값으로 닫은 성장 점검 항목이 성장 지점의 근거나 기능 후보의 출처에 한 번 이상 나온다
- [ ] 수집 원칙 네 항목이 모두 값, `해당 없음`, `미정` 중 하나로 닫혔다
- [ ] 측정 계획의 이벤트 칸이 입력 산출물의 이벤트 ID이거나 `미정`(확인처·담당·기한)이고 이벤트 ID를 새로 만들지 않았다
- [ ] 측정 계획의 행마다 연결 지표나 성장 지점 중 하나 이상이 ID로 쓰여 있다
- [ ] 측정 계획의 주요 속성에 수집 원칙이 담지 않기로 한 정보가 없다
- [ ] 입력 산출물의 모든 목표가 지표 매핑에 한 행씩 있고 계산 근거가 닫혔다
- [ ] 계산 근거가 이벤트 집계인 목표는 측정 계획의 연결 지표에 한 번 이상 나온다
- [ ] 기능 후보의 출처 ID가 모두 앞 표에 있고 성장 지점의 판정이 기능 필요인 행마다 후보가 한 개 이상 있다(입력 산출물에 같은 기능의 후보가 있으면 근거가 그 ID를 가리키는 추적용 행이다)
- [ ] 측정 계획에 행이 있으면 그 기록을 남기고 보내는 측정 기능 후보가 한 개 이상 있다
- [ ] 후속 후보, 설계 기준, 프로세스가 기능 후보와 구분되어 있다
- [ ] 입력에 없는 지표 값, 이벤트 ID, 분석 도구 이름, 업체 이름을 만들어 쓰지 않았다
