## 완료 체크 (35)

- [ ] 모든 표의 모든 칸이 값, `해당 없음`, `미정` 중 하나로 닫혔다
- [ ] 워크스루의 대상 액터, 플로우, 화면이 입력 산출물에 있는 ID이고 따라간 기능이 기능 트리에 있는 기능 ID이다
- [ ] 결과가 끊김 있음인 워크스루 행마다 발견 표에 출처로 그 행을 가리키는 행이 있다
- [ ] 역할 검토의 의견, 검토자, 결과, 일자와 프로토타입의 참가자 수, 완료 수, 찾지 못한 것, 기대했으나 없던 것은 사람이 준 기록에서 옮긴 값이거나 `미정`이다
- [ ] 발견의 출처가 모두 워크스루, 역할검토, 프로토타입 표의 ID이다
- [ ] 조치 유형이 변경 없음이 아닌 발견은 환류 대상이 앞 단계의 번호와 이름이거나 `해당 없음`(사유)이고 반영 상태가 값이며, 조치 유형이 기능 추가이고 반영 대기인 발견의 대상 기능은 `미정`이다
- [ ] 라운드 표의 수행이 세 표의 라운드 칸과 맞고 신규 발견 수가 변경 없음 수를 뺀 발견의 수와 같다
- [ ] 종료 조건 다섯 가지의 판정이 위 표에서 나왔고, 필요한 사람의 기록이 없는 조건은 `미정`이며, 종료 판정은 다섯이 모두 충족일 때만 충족이다
- [ ] 집계의 발견 수가 여섯 조치 유형 수의 합과 같고 역할 수가 네 결과 수의 합과 같다
- [ ] 집계의 닿은 기능 수와 닿지 못한 기능 수의 합이 기능 트리의 기능 행의 수와 같다
- [ ] 집계의 v1.0 후보 기능 수가 입력 기능 수에 기능 추가 수를 더하고 기능 삭제 수를 뺀 수와 같다
- [ ] 입력에 없는 기능 ID, 액터, 화면, 사람의 의견·서명·테스트 결과가 값으로 쓰이지 않았다
