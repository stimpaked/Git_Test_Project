## 완료 체크 (17)

- [ ] 화면 인벤토리의 모든 칸이 값, `해당 없음`, `미정` 중 하나로 닫혔다
- [ ] 입력 산출물에 나온 화면이 모두 화면 인벤토리에 있고 같은 화면이 같은 플랫폼에서 두 행에 없다
- [ ] 사용 액터의 모든 ID가 액터 목록(사람)에 있고 서비스 안의 구성요소가 사용 액터에 없다
- [ ] 유저 플로우에서 이 단계가 맡기로 한 목표가 화면 인벤토리의 관련 목표에 반영되었다
- [ ] 핵심 화면으로 표시한 화면마다 비정상 상태 표에 상태 아홉 가지가 모두 한 행 이상 있다
- [ ] 비정상 상태 표의 화면이 모두 핵심 화면이다
- [ ] `제외` 행은 같은 화면과 상태의 다른 판정 행과 섞이지 않았다
- [ ] `제외` 행마다 동작이 `해당 없음`과 구체적인 사유로 닫혔다
- [ ] `제공` 행마다 근거가 입력 산출물의 항목으로 시작한다
- [ ] 판정이 `후보`인 화면과 상태 행이 모두 후보 목록의 출처에 있고 후보 목록의 출처는 모두 화면 인벤토리나 비정상 상태 표에 있다
