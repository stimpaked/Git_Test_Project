## 완료 체크 (31)

- [ ] 모든 표의 모든 칸이 값, `해당 없음`, `미정` 중 하나로 닫혔다
- [ ] 후보 표를 가진 입력 산출물의 후보 표가 모두 표별 소진에 한 행씩 있다
- [ ] 입력 후보의 ID마다 제외 목록의 후보 ID와 기능 목록의 병합 후보 가운데 정확히 한 곳에 한 번만 나온다
- [ ] 후보 ID를 입력의 표기 그대로 하나씩 쉼표로 썼고 `~` 같은 범위 표기가 없다
- [ ] 구분이 설계 기준이나 프로세스인 후보는 모두 제외 목록에 있고 기능 목록의 병합 후보에 없다
- [ ] 기능 목록의 한 행에 합친 후보의 구분은 모두 같고 행의 구분과 맞다(기능 후보는 기능, 후속 후보는 후속)
- [ ] 한 행에 합친 후보의 영역과 공통·고유가 서로 갈리지 않고 행의 영역과 공통·고유와 맞다
- [ ] 모든 기능에 병합 후보가 한 개 이상 있고 후보 없이 만든 기능이 없다
- [ ] 기능명이 대상과 동작으로 쓰였고 정책 값이 없으며 용어집의 사용하지 않는 동의어가 없다
- [ ] 같은 기능명이 기능 목록에 두 번 나오지 않는다
- [ ] 영역 칸이 영역 목록의 `Z-` ID이거나 `미정`(확인처·담당·기한)이다
- [ ] 표별 소진의 행마다 후보 수가 기능 병합 수와 기능 아님 수의 합과 같다
- [ ] 집계의 합계가 입력 후보 수와 같고 기능 수가 기능 목록의 행 수와 같다
- [ ] 입력에 없는 후보, 기능, 영역, 용어가 값으로 쓰이지 않았다
