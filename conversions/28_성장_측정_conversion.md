## ③ 도메인 교체 시험

작성 에이전트 역할의 별도 세션 둘에게 이 단계의 템플릿과 단계 가이드, 공통 가이드, 규칙_공통 3절, 도메인별 입력 자료와 이전 단계 산출물(01~25번 시험 산출물)만 주고 26번부터 28번까지 순서대로 산출물을 쓰게 했다. 둘은 서로의 결과를 보지 못했고 이 분석서와 결정 로그도 읽지 않았다. 도메인은 가상이며 앞선 시험과 같다. 시험으로 쓴 산출물은 이 문서에 넣지 않는다(CV-12). 산출물마다 `tools/check_deliverable.py`로 구조와 공통 규칙을, 01~28번 산출물 묶음에 `tools/check_chain.py`로 ID 참조를 검사했다(두 도메인 모두 실패 0). 사람이 주는 자료(운영 업무·처리량, 요금·수익 계획, 유입 채널, 분석 도구)가 입력에 없어 `미정`이 많은 것은 입력 부족이다. 변환 분석서의 상태는 사용자가 그룹 단위로 확인할 때까지 `초안`이다.
