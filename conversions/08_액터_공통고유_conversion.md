| OM-02 | 샘플의 공통 정의는 "같은 목표를 가진다"뿐이라, 이름은 같은데 방식이 달라 합치지 않아야 하는 목표를 어떻게 남기는지 샘플에 없다. 합치지 않은 쪽의 이유가 남아야 중복 설계 여부를 검증할 수 있다 | 목적 대비 | 반영: 08.목표판정.판정, 08.목표판정.근거(비교한 목표의 ID). 같은 방식의 기준은 판단이라 단계 가이드가 맡는다 |
| OM-03 | 샘플의 목표 목록은 같은 방식의 목표를 이미 하나로 적어서 이 단계의 판정이 확인에 그친다. 단계 정의의 목표 목록은 칸마다 액터의 목표를 정하므로 액터마다 비슷한 목표가 따로 있을 수 있고, 이를 하나로 합쳐 한 번만 정의할 자리와 이름이 필요하다 | 목적 대비 | 반영: 표:공통목표(정의 ID `K`), 08.목표판정.공통 목표 ID |
| OM-04 | 모든 목표가 판정되었는지, 판정하지 못한 채 남은 목표가 몇인지 알 방법이 샘플에 없다. 샘플의 집계는 세 판정의 합이 전체와 같다고만 확인한다 | 목적 대비 | 반영: 08.집계.판정 미정 목표 수 |
| OM-05 | 샘플은 판정마다 표를 나눠, 목표 목록의 목표가 어느 판정 표에도 없는 경우를 찾을 수 없다 | 목적 대비 | 반영: 표:목표판정(한 목표 한 행), 08.집계.합계, 08.집계.목표 목록의 목표 수 |

### 도메인 대입

대입한 가상 도메인은 사내 휴가 신청 도구, 어린이 독서 앱, 병원 예약 서비스, 스마트 온실 모니터링 서비스 네 가지다.

| ID | 발견 내용 | 발견 방법 | 처리 |
|---|---|---|---|
| OM-06 | 사내 휴가 신청 도구에서 구성원이 직접 휴가를 신청하는 일과 팀 관리자가 구성원 대신 신청하는 일은 목표 이름이 같고 대리일 때만 신청자를 지정하는 단계가 늘어난다. 이 차이를 분기로 쓸 수 있는지, 별도 목표로 나눌지가 갈린다 | 도메인 대입: 사내 휴가 신청 도구 | 반영: 08.공통목표.액터별 차이(분기). 분기로 쓸지 나눌지의 기준은 판단이라 단계 가이드가 맡는다 |
| OM-07 | 사내 휴가 신청 도구에서 구성원과 사내 인사 시스템이 모두 잔여 휴가 일수를 조회하는 목표를 가진다. 사람과 사람이 아닌 액터가 같은 목표를 가지면 샘플의 시스템 정의(외부·시간 액터의 목표)로는 공통과 시스템 중 어느 쪽인지 정할 수 없다 | 도메인 대입: 사내 휴가 신청 도구 | 반영: 08.목표판정.판정(시스템을 사람이 아닌 액터만 가진 목표로 일반화한다, SA-11). 섞인 경우의 기준은 단계 가이드가 맡는다 |
| OM-08 | 어린이 독서 앱에서 어린이의 가입과 보호자가 대신 하는 가입은 이름이 비슷하지만 보호자 동의 단계와 계정을 만드는 주체가 달라 흐름이 다르다. 이런 목표는 합치지 않아야 하고, 합치지 않은 이유가 남아야 한다 | 도메인 대입: 어린이 독서 앱 | 반영: 08.목표판정.근거(OM-02와 같은 칸) |
| OM-09 | 스마트 온실 모니터링 서비스에서 센서(장치)와 고객 시스템의 호출 프로그램(자동 호출 주체)이 둘 다 측정값을 보내는 목표를 가진다. 비사람 액터끼리 같은 목표를 가질 수 있는데 샘플은 액터와 목표를 범위로 맞대어 목표 단위의 대응이 없다 | 도메인 대입: 스마트 온실 모니터링 서비스 | 반영: 08.목표판정.액터(여러 액터를 쉼표로 쓴다). 비사람 액터끼리 같은 방식인 목표에 공통 목표 ID를 주는 것은 반영하지 않음: 시스템 목표는 앱 플로우의 연동 지점으로 표기하고 상세화는 연동과 시간·주기 단계가 맡는다는 샘플의 처리를 따른다(SA-12) |
| OM-10 | 병원 예약 서비스에서 목표 목록의 목표 하나 "예약을 변경한다"에 환자, 접수 담당, 진료 의사가 적혀 있고 환자와 접수 담당만 같은 방식이다. 의사는 일정을 조정하는 흐름이라 다르다. 목표 하나에 판정 하나만 쓸 수 있어 일부 액터만 같은 방식인 경우를 담을 수 없다 | 도메인 대입: 병원 예약 서비스 | 반영: 08.목표판정.판정(판정을 `미정`으로 닫고 확인처에 목표 목록의 분리를 쓴다). 목표를 액터별로 나누는 일은 목표 목록의 몫이라 인터페이스 표에 환류로 둔다 |
| OM-11 | 어린이 독서 앱에서 같은 어린이라도 보호자 동의 전과 후에 쓸 수 있는 범위가 다르다. 사람이 상태에 따라 다르게 취급되는 경우를 별도 액터가 아니라 목표의 분기로 써야 할 때가 있다 | 도메인 대입: 어린이 독서 앱 | 반영: 08.공통목표.액터별 차이(분기). 상태에 따른 차이도 같은 칸에 쓴다는 기준은 단계 가이드가 맡는다 |
