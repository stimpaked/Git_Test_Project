# 변환 분석서 — 33. 의존성

> 샘플 `33_의존성.md`를 템플릿 `templates/33_의존성_template.md`로 바꾸는 과정의 분석 기록이다(`docs/규칙_변환분석서.md`).
> 샘플은 장기 삭제 대상이라 샘플 요소는 원문 발췌로 인용한다. 샘플의 오류와 도메인 편향은 이 문서에만 기록하고 샘플은 고치지 않는다.
> 샘플의 영역 간 호출 매트릭스 두 개, 공통 기능 호출 현황 67행, 웨이브 11행은 같은 틀을 되풀이하므로 값은 표 단위로 묶어 한 줄로 해부했다(CV-06). 다만 열과 판정 값처럼 템플릿의 열과 선택지가 되는 것은 따로 해부했다.
> 04·05번과의 차이: 04·05번은 후보를 찾는 질문에서 시작하지만 이 단계는 후보를 새로 찾지 않는다. 앞 단계가 만든 기능 트리의 기능 사이에 관계를 붙이는 단계라 행의 단위가 기능 사이의 호출 한 건, 선후행 한 건, 기능 한 개의 웨이브, 공통 기능 한 개의 검사다. 이 차이가 표 구성에 반영된 곳은 SA-08~SA-10, SA-16~SA-27과 OM-01~OM-15다.
> 샘플은 관계의 원본을 적지 않고 결과만 적는다(OM-01). 영역 간 매트릭스, 공통 기능별 호출 현황(호출하는 기능은 최대 6개), 웨이브별 기능 목록이 모두 호출과 선후행에서 파생되는 값인데 파생의 원본인 호출 목록과 선후행 목록이 문서 어디에도 없다.

## ③ 도메인 교체 시험

도메인 교체 시험은 작업 순서 6단계에서 템플릿과 단계 가이드를 쓴 뒤에 한다. 이 분석서는 그때까지 상태를 `초안`으로 둔다.
