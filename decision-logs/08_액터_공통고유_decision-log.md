### DL-08-001 · 08번 변환 분석서와 템플릿 v1.0, 단계 가이드 v1.0 초안을 작성한다
- **날짜:** 2026-10-08
- **대상:** `conversions/08_액터_공통고유_conversion.md`, `templates/08_액터_공통고유_template.md`, `guides/08_액터_공통고유_guide.md` (04번, 05번에 이은 복제)
- **결정 주체:** 사용자 승인 (그룹 단위 진행을 승인함(DL-05-005))
- **배경:** 샘플 해부 37행(SA-01~37)과 누락 탐색 11행(OM-01~11)을 04번, 05번과 같은 절차로 만들었다. 단계 정의의 목적은 목표를 같은 방식으로 하는 것과 특정 액터만 하는 것으로 가려 중복 설계를 막는 것이다. 샘플은 판정마다 표를 나누고 판정 이유를 적는 칸이 없다(SA-14, OM-01).
- **검토한 대안:** 04번, 05번처럼 도출 질문 → 후보 → 판정 → 목록의 네 단계로 구성하는 안과, 공통 목표 정의 → 목표 판정 → 집계의 세 표로 구성하는 안을 비교했다. 목표 목록이 이미 주어진 입력이라 후보를 찾는 질문이 필요 없고 판정과 정의가 핵심이라 뒤의 안을 골랐다.
- **결정:** 값 표 셋을 둔다. 공통목표(정의 ID `K`, 목록 표), 목표판정(목록 표, 정의 ID 없음), 집계(속성 표, 정의 ID 없음). 선택 블록과 표 없는 절은 없다. 샘플의 `판정 규칙` 절과 `이후 단계에서의 사용 예` 절은 각각 단계 가이드와 인터페이스 표가 맡는다(SA-08, SA-29).
- **이유:** 템플릿의 모든 표와 필드가 분석서의 줄에 대응한다(정의서 6절 4번).
- **영향:** 도메인 교체 시험(작업 순서 8번)이 남았다. 시험 전까지 변환 분석서의 상태는 `초안`이다. 인터페이스 표는 DL-08-002.
- **상태:** 유효

### DL-08-002 · 인터페이스 표: 04번 잠정 줄을 필드 수준으로 바꾸고 08번 연결을 추가한다
- **날짜:** 2026-10-08
- **대상:** `tools/data/interfaces.csv` (IF-04-025 수정, IF-08-001~027 추가)
- **결정 주체:** 유지보수자 판단
- **배경:** 08번 템플릿이 생겨 04번이 08번으로 보내던 문서 수준 잠정 줄 IF-04-025를 필드 수준으로 바꿀 수 있게 되었다(IR-10). 템플릿 필드 17개는 모두 보내는 필드로 한 줄 이상 나와야 한다(IR-07). 쓰이는 곳은 샘플의 머리말과 `이후 단계에서의 사용 예` 표가 뒷받침한다(SA-07, SA-29~33).
- **검토한 대안:** 해당 없음 — 규칙(IR-07, IR-10)을 따랐다.
- **결정:** IF-04-025의 받는 쪽을 `08.목표판정.액터`로 바꾸었다. 08번 연결은 27줄이다. 소비자가 있는 줄 17은 받는 쪽 템플릿이 아직 없어 모두 문서 수준 잠정 값(`NN`)이며 받는 단계는 09, 15, 32, 34와 환류의 07이다. 소비자가 없는 줄 10은 `최종 소비자 없음`과 사유로 닫았다(집계의 여섯 항목, 공통 목표의 이름과 근거, 판정 표의 목표 문장과 근거). 샘플의 쓰이는 곳 표시나 사용 예 표가 뒷받침하지 않는 소비자는 두지 않았다. 판정이 `미정`인 목표를 목표 목록이 나누게 하는 환류를 더했다(OM-10).
- **이유:** 템플릿 필드마다 소비자가 있거나 사유가 있어야 한다. 집계는 이 산출물 안의 완결성 점검이라 뒤 단계의 쓰임을 뒷받침하는 근거가 없어 소비자를 만들지 않았다.
- **영향:** 07, 09, 15, 32, 34번 템플릿이 생기면 해당 잠정 줄을 필드 수준으로 바꾼다. 이 단계의 입력은 목표 목록과 두 액터 목록이지만 07번에서 08번으로, 05번에서 08번으로 보내는 줄은 이 복사본에 없다. 사람 액터 ID를 받는 줄(IF-04-025)만 있어 템플릿 머리말의 입력이 04번만 보인다. 07번과 05번 세트를 만드는 쪽이 08번으로 가는 줄을 더해야 한다.
- **상태:** 검토 대기

### DL-08-003 · 공통 목표에 자체 ID를 주고 목표 판정 표를 목표 목록의 목표당 한 행으로 둔다
- **날짜:** 2026-10-08
- **대상:** `templates/08_액터_공통고유_template.md` 1, 2절 (표 `공통목표`, `목표판정`)
- **결정 주체:** 유지보수자 판단
- **배경:** 샘플은 공통·고유·시스템 세 표로 나누고(SA-14), 공통 표는 목표 목록의 ID를 그대로 쓴다(SA-16). 샘플의 목표 목록은 같은 방식의 목표를 이미 하나로 적어 이 단계가 확인에 그친다(OM-03). 고유와 시스템 표는 목표 ID를 한 칸에 모으거나 범위로 적어 목표 단위의 판정과 근거가 없다(SA-23, SA-25, OM-05).
- **검토한 대안:** (가) 샘플처럼 판정마다 표를 나눈다 / (나) 목표 판정 표 하나만 두고 공통 목표는 같은 값을 가진 행으로 본다 / (다) 공통 목표를 한 번 정의하는 표와 목표당 한 행의 판정 표를 둔다
- **결정:** (다). 공통 목표 표에 정의 ID `K`를 부여하고(작성 순서상 판정 표보다 앞에 둔다, TP-16), 판정 표의 `공통 목표 ID` 열이 그 ID를 참조한다. 액터가 합쳐진 공통 목표의 공통 액터는 판정 표의 액터를 합친 것과 같아야 하며 이는 가이드가 다룬다.
- **이유:** (가)는 판정되지 않은 목표를 찾을 수 없다. (나)는 공통 목표를 한 번만 정의한다는 단계 정의의 산출물을 표로 보여 줄 수 없고 액터별 차이를 적을 자리가 없다.
- **영향:** 뒤 단계는 공통 목표 ID를 플로우 한 장의 단위로 참조한다(IF-08-001). 공통 액터와 판정 표의 액터는 같은 사실을 두 곳에서 말하므로 어긋나면 사람이 찾아야 한다(검사 도구가 없다).
- **상태:** 검토 대기

### DL-08-004 · 공통의 기준을 "같은 방식"으로 하고, 근거 없이 합치지 않는다
- **날짜:** 2026-10-08
- **대상:** `guides/08_액터_공통고유_guide.md` 3.1, 3.2절, `templates/08_액터_공통고유_template.md` 목표판정 표의 판정·근거 열
- **결정 주체:** 유지보수자 판단
- **배경:** 샘플은 공통을 "2개 이상의 액터가 같은 목표를 가진다"로 정의한다(SA-09). 단계 정의의 목적은 같은 방식으로 하는 것을 가리는 것이라, 이름은 같고 방식이 다른 목표는 합치지 않아야 한다(OM-02, OM-06, OM-08).
- **검토한 대안:** (가) 샘플의 기준을 그대로 쓴다 / (나) 04번 판정 테스트처럼 비교 항목을 두고 하나라도 다르면 분리한다 / (다) (나)에 더해 분기로 쓸 수 있는 차이를 정의한다
- **결정:** (다). 비교 항목은 이루려는 결과, 거치는 주요 단계, 쓰는 화면이나 도구, 다루는 데이터 네 가지이고, 시작하는 쪽·상대 역할·대상의 종류·볼 수 있는 범위·조건에 붙는 경고나 확인은 분기로 쓸 수 있는 차이로 본다. 같다고 볼 근거가 입력에 없으면 합치지 않고, 근거 없이 `가정`으로 합치지 않는다.
- **이유:** 흐름이 아직 그려지지 않은 단계라 과도하게 합치면 이후 플로우가 틀리고, 04번 가이드가 병합에 같은 보수적 기준을 쓴다. 분기의 허용 범위를 정하지 않으면 샘플의 공통 목표 사례(역할마다 시작하는 쪽만 다른 경우)와 맞지 않는다.
- **영향:** 비교 항목의 구체 기준은 도메인 교체 시험에서 작성자마다 갈리는지 본다. 합치는 쪽이 지나치게 줄어 `미정`이 많아지면 기준을 조정한다.
- **상태:** 검토 대기

### DL-08-005 · 시스템 판정을 유지하되 사람이 아닌 액터만 가진 목표로 일반화하고, 일부 액터만 같은 방식인 목표는 `미정`으로 닫아 목표 목록에 환류한다
- **날짜:** 2026-10-08
- **대상:** `templates/08_액터_공통고유_template.md` 목표판정 표의 판정 열, `guides/08_액터_공통고유_guide.md` 3.2, 5절, `tools/data/interfaces.csv` (IF-08-018)
- **결정 주체:** 유지보수자 판단
- **배경:** 샘플의 `시스템`은 외부·시간 액터의 목표다(SA-11). 비사람 액터에는 장치와 자동 호출 주체도 있고(OM-07, OM-09), 사람과 사람이 아닌 액터가 같은 목표를 가질 수 있다(OM-07). 목표 하나에 여러 액터가 적혀 있고 일부만 같은 방식이면 판정 표의 한 행에 판정을 하나만 쓸 수 있다(OM-10).
- **검토한 대안:** 판정: (가) 공통·고유 둘로 줄이고 사람인지는 액터 ID로 읽게 한다 / (나) 샘플의 세 값을 유지하고 `시스템`을 일반화한다. 일부만 같은 경우: (다) 행을 액터 묶음별로 나눈다 / (라) 판정을 `미정`으로 닫고 목표 목록에 환류한다
- **결정:** (나), (라). `시스템`은 목표에 적힌 액터가 모두 비사람 액터인 경우, 사람과 사람이 아닌 액터가 섞였으면 `공통`이다. 사람이 아닌 액터끼리 같은 방식인 목표에 공통 목표 ID는 주지 않고 액터 칸에 모두 쓴다. 환류의 받는 쪽은 07번이다.
- **이유:** 뒤 단계가 샘플의 세 판정을 그대로 소비하는 것으로 가정하고 있어(SA-12) (가)는 보수적이지 않다. (다)는 행이 목표 ID로 유일하지 않아 집계와 목표 목록의 대조가 깨진다.
- **영향:** 사용자 확인이 필요한 질문이다: `시스템`을 판정으로 유지하는 것이 맞는가, 아니면 사람 여부를 액터 ID로 읽는 이분법이 나은가. 07번 템플릿이 목표를 액터별로 나누는 구조인지에 따라 (라)의 빈도가 달라진다.
- **상태:** 검토 대기

### DL-08-006 · 집계를 속성 표로 두고 판정 미정 목표 수를 더한다
- **날짜:** 2026-10-08
- **대상:** `templates/08_액터_공통고유_template.md` 3절 (표 `집계`)
- **결정 주체:** 유지보수자 판단
- **배경:** 샘플의 집계는 판정별 목표 수와 합계가 전체와 같다는 확인이다(SA-26, SA-28). 판정을 닫지 못한 목표는 세는 곳이 없다(OM-04).
- **검토한 대안:** (가) 목록 표(판정, 목표 수)로 둔다 / (나) 항목이 고정된 속성 표로 두고 목표 목록의 목표 수를 항목으로 더한다
- **결정:** (나). 여섯 항목: 판정별 수 셋, 판정 미정 목표 수, 합계, 목표 목록의 목표 수.
- **이유:** 항목이 고정되어 있어 필드 키로 가리킬 수 있고, 목록 쪽 수를 같은 표에서 대조할 수 있다.
- **영향:** 집계 여섯 필드는 뒤 단계가 쓰지 않아 `최종 소비자 없음`이다(DL-08-002).
- **상태:** 검토 대기

### DL-08-007 · 공통 목표의 액터별 차이가 없을 때 `없음`이 아니라 `해당 없음`과 사유로 닫는다
- **날짜:** 2026-10-08
- **대상:** `guides/08_액터_공통고유_guide.md` 3.1, 5, 6절, `templates/08_액터_공통고유_template.md` 공통목표 표의 액터별 차이(분기) 열
- **결정 주체:** 유지보수자 판단
- **배경:** 샘플은 차이가 없을 때 값 `없음`을 쓰고(SA-20), 차이 칸에 뒤 단계 번호를 적는다(SA-21). `없음`은 공통 규칙의 닫는 말 `해당 없음`, `미정`과 달라 차이가 없다는 뜻인지 모른다는 뜻인지 갈린다.
- **검토한 대안:** (가) `없음`을 값으로 허용한다 / (나) `해당 없음`과 비교 항목이 모두 같다고 본 사유로 닫는다
- **결정:** (나). 규칙 문서는 바꾸지 않는다. 뒤 단계에서의 쓰임은 분기 칸에 쓰지 않고 인터페이스 표(IF-08-006, 007)가 갖는다.
- **이유:** 공통 규칙 CM-04, CM-08과 05번 가이드의 선례(관련 제약·규제)와 같다. 칸이 비어 보이는 대신 근거가 남는다.
- **영향:** 해당 없음.
- **상태:** 검토 대기

### DL-08-008 · 도메인 교체 시험 결과를 반영한다

- **대상:** `conversions/08_액터_공통고유_conversion.md` ③ (DT-01~06), `guides/08_액터_공통고유_guide.md` 3.2, 3.3
- **결정 주체:** 유지보수자 판단
- **배경:** 두 도메인 시험에서 집계와 판정 표의 근거를 설명 문장으로 시작해 CM-K04가 실패했다. 가이드의 예시 어순이 참조로 시작하는 규칙(CM-18)과 맞지 않았다(DT-03, DT-06).

- **결정:** 집계 근거는 `NN 산출물 이름` 참조로 시작하고, 액터가 하나뿐인 경우의 근거는 목표 ID로 시작해 사실을 이어 쓰게 했다.
- **이유:** 작성 에이전트가 가이드대로 쓰면 검사가 통과해야 한다.
- **영향:** 단계 가이드 v1.1.
- **상태:** 검토 대기
