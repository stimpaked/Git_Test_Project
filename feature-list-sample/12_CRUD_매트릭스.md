## 1. 범례

**열:** C 생성 · R 조회 · U 수정 · D 삭제 · L 목록 · S 검색 · A 보관·숨김 · X 복원 · I 가져오기 · O 내보내기 · H 공유 · V 감사 기록

**셀 값:** 액터 ID(해당 행위를 하는 주체) · 본인(소유자) · 시스템(자동) · T-01(시간 트리거)

**N/A 사유 코드**

| 코드 | 의미 |
|---|---|
| N1 | 정책상 제공하지 않음(사유는 아래 비고) |
| N2 | 감사 기록 대상이 아님(일반 접근 로그로 충분) |
| N3 | MVP 범위 외(Later 목록 번호 참조) |
| N4 | 해당 개념이 없음 |

> **규칙:** 모든 칸은 액터/시스템 값이거나 N 코드여야 합니다(빈 칸 없음).

## 3. N1(정책상 제공하지 않음) 주요 사유

| 엔티티·열 | 사유 |
|---|---|
| E-01 I(가져오기), 전 엔티티 I | 사용자 데이터를 외부에서 일괄 가져오는 시나리오가 없다 |
| E-02 H(프로필 공유) | 프로필 링크 공유는 제공하지 않는다(거래는 글 중심) |
| E-04 O, E-11 O 등 | 사용자 직접 내보내기는 MVP 범위 외, 개인정보 열람 요청은 CS 처리(LT-09) |
| E-07·E-08 S(채팅 검색) | 인터뷰에서 요구가 없었고 구현 비용 대비 효용이 낮다 |
| E-12 D, E-13 D, E-14 D | 신고·제재·이의제기는 분쟁 대응을 위해 삭제하지 않고 보존한다 |
| E-18 D(문의) | 운영·분쟁 근거로 보존한다 |
| E-19 U(동의 이력 수정) | 이력은 수정하지 않고 새 행을 추가한다 |
| E-23 D(관리자 계정 삭제) | 감사 추적을 위해 삭제 대신 비활성화한다 |
| E-27 D(설정값 삭제) | 변경 이력 보존을 위해 삭제하지 않는다 |
