# 30. 유사 서비스·조사 근거 대조

> **샘플 문서** · 가상 서비스 "이웃장터" 기준 · 작성일 2026-10-06 · v1.0 · 작성 PM(가상) · 상태 승인
>
> 비교 대상(서비스 A·B·C)은 03번의 **가상 비교표**입니다. 실제 서비스의 기능 제공 여부를 나타내지 않습니다.

| 구분 | 내용 |
|---|---|
| 단계 | 30 / 36 — H. 대조(외부 기준) |
| 입력 | 03(유사 서비스 기능표·인사이트), 후보 풀 전체 |
| 산출물 | 항목별 채택/제외 판정, 갭 목록, Kano 분류 |
| 이 산출물이 쓰이는 곳 | 29와 동일(갭 → 후보 풀) · 36(우선순위: Kano 판단 근거) |

> **Kano 분류:** 기본(없으면 불만, 있어도 감동 없음) · 기대(많을수록 만족) · 매력(없어도 불만 없으나 있으면 감동). 경쟁 서비스 대부분이 제공하는 기능은 기본·기대로 보고 후순위로 미룰 때 근거를 남깁니다.
