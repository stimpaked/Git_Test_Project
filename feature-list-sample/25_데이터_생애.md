## 2. 공통 정책

| ID | 정책 | 내용 |
|---|---|---|
| DL-01 | 탈퇴 유예 | 탈퇴 신청 후 7일(샘플) 동안 복구 가능, 만료 시 개인정보 파기·콘텐츠 익명화(Q-108, Q-109) |
| DL-02 | 분리 보관 | 법정 보존 대상은 서비스 DB와 분리해 접근을 제한하고 기간 경과 시 파기한다 |
| DL-03 | 익명화 규칙 | 타인과 공유된 콘텐츠(후기·메시지·글)는 삭제 대신 작성자 표시를 "탈퇴한 사용자"로 바꿔 유지한다 |
| DL-04 | 백업 | 일 단위 백업, 보존 35일(샘플), 복구 목표 RPO 15분·RTO 2시간(NF-13). 백업 속 개인정보는 보존 기간 경과 시 함께 폐기된다 |
| DL-05 | 열람·내보내기 | MVP는 문의 접수 후 CS가 처리(CF-25-03), 셀프서비스는 Later(LT-09) |
| DL-06 | 이전(마이그레이션) | 스키마 변경과 데이터 이전은 운영 프로세스(변경 관리)로 수행 — 기능 목록 대상 아님 |
