## 3. 소유·공유·위임·승인 규칙

| ID | 구분 | 규칙 |
|---|---|---|
| OWN-01 | 소유 | 글·프로필·관심·차단·알림 설정은 작성자(본인)만 수정·삭제할 수 있다 |
| OWN-02 | 소유 | 채팅방·약속·후기는 참여자(당사자)만 접근한다. 운영자는 신고 연계 건에 한해 열람한다 |
| OWN-03 | 소유 | 블라인드된 글의 소유자는 수정할 수 없고, 이의제기만 할 수 있다 |
| SHR-01 | 공유 | 글은 링크로 공유할 수 있다. 비로그인 열람 범위는 행위 1번(제한)을 따른다 |
| SHR-02 | 공유 | 프로필·채팅방·후기는 링크 공유를 제공하지 않는다 |
| DLG-01 | 위임 | 거래·계정 권한의 위임은 제공하지 않는다(대리 판매·대리 구매 없음) |
| DLG-02 | 위임 | 관리자 간 업무 이관은 처리 담당자 재지정(신고·문의)으로만 한다 |
| APR-01 | 승인 | 영구정지는 신청자와 다른 A-04 또는 A-06의 승인이 있어야 확정된다(2인 승인) |
| APR-02 | 승인 | 개인정보 원문 열람은 사유 입력 후에만 가능하고 감사 로그에 기록된다 |
| APR-03 | 승인 | 관리자 역할·권한 변경은 A-06만 할 수 있고 감사 로그에 기록된다 |
| BLK-01 | 차단 | 차단 관계에서는 글·프로필·채팅이 서로에게 보이지 않는다 |
