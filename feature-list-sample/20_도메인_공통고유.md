## 3. 혼합 판정(분리) 사례

| 대상 | 09번 잠정 태그 | 확정 | 분리 내용 |
|---|---|---|---|
| 신고 | 접수 공통 / 처리 고유 | **혼합** | 접수 화면·이력(공통: 대상 유형을 파라미터로 받음) + 조치·제재 정책(고유) |
| 알림 | 공통 | **혼합** | 발송·토큰·목록(공통) + 이벤트별 문구·딥링크 정의(고유 — 각 영역이 템플릿을 등록) |
| 이미지 | 공통 | **혼합** | 업로드·변환(공통) + 글 사진 최대 장수·대표 사진 규칙(고유) |
| 탈퇴 | 공통 | **혼합** | 탈퇴 절차·유예·파기(공통) + 진행 중 거래·작성 콘텐츠 처리 규칙(고유: Q-106, Q-109) |
| 약관 고지 | 공통 | **혼합** | 약관 노출·동의 장치(공통) + 통신판매중개자 고지 문구(고유: Q-054) |
| 비로그인 열람 | 고유 | **혼합** | 비로그인 접근 통제(공통) + 열람 가능한 글 정보 범위(고유: Q-053) |
| 검색 | 고유 | **고유** | 글 검색은 도메인 규칙(동네 필터·카테고리)이 본질이라 분리하지 않음 |
| 차단 | 고유 | **고유** | 상호 비노출 규칙이 글·채팅·프로필에 걸쳐 있어 도메인 특화 |
